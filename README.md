# インタラクティブ行列学習ラボ (Interactive Matrix Lab) - 仕様・要件定義書

行列（Matrix）の概念、計算手順、実用的な応用例（2D線形変換）を視覚的かつインタラクティブに学習できる、Webベースの教育用アプリケーションです。

---

## 1. プロジェクト概要

数学の「行列」は、3Dグラフィックス、ゲーム開発、物理シミュレーション、データサイエンス、AI・機械学習など、現代のあらゆるテクノロジーの基礎を支えています。
しかし、数字がグリッド状に並んだ抽象的な外観や、行列の掛け算の複雑な計算ルール、座標変換のイメージの掴みにくさから、多くの学習者が挫折しやすい分野でもあります。

本アプリケーションは、**「手で触って、目で見て、ステップ単位で理解する」**をコンセプトに、行列の基礎から応用までを完全に直感化することを目的とします。

---

## 2. コア機能要件

### ① ステップバイステップ学習システム (Learning Theory)
単に数式を読むだけでなく、数式の各要素が何を表しているかをインタラクティブに確認できます。
*   **行列の基本概念**: 行（Row）と列（Column）の定義、行列のサイズ（次元）、成分のインデックス表現をホバーやアニメーションで視覚化。
*   **たし算・ひき算・定数倍**: 同じ位置の成分同士を計算する流れを、要素ごとにステップ再生アニメーションで図示。
*   **行列の掛け算（積）**: 最もつまずきやすい「左の行 × 右の列」の組み合わせと和の計算プロセスを、インタラクティブに1ステップずつハイライト・計算進行しながら解説。

### ② グラフィカル座標変換シミュレーター (2D Linear Transformation)
行列が「空間をどのように変換（変形）するのか」をリアルタイムで視覚化します。
*   **2x2 変換行列のリアルタイム操作**: 2x2 行列 $M = \begin{pmatrix} a & b \\ c & d \end{pmatrix}$ の各成分（$a, b, c, d$）をスライダーで変更。
*   **空間の変形アニメーション**: グリッド空間、ベクトル、幾何学的な図形（F文字やカスタムキャラクター）が、行列値の変更に伴って滑らかに変形。
*   **プリセット機能**: 代表的な一次変換をワンクリックで適用。
    *   *恒等変換*（何もしない）
    *   *拡大・縮小*（Scaling）
    *   *回転*（Rotation）
    *   *剪断*（Shearing）
    *   *反射・対称移動*（Reflection / x軸・y軸）
*   **座標点追跡**: 空間上の点をドラッグして移動させ、その座標ベクトルに行列が乗算され、変換後のベクトル（$M \vec{v}$）にどうマッピングされるかをリアルタイムに数式とグラフで表示。

### ③ インタラクティブ行列計算機 (Interactive Matrix Calculator)
任意の2次元または3次元行列を入力し、計算結果とその詳細な計算手順を表示するツール。
*   **サイズ選択**: $2 \times 2$ または $3 \times 3$ の切り替え。
*   **演算の選択**: 行列AとBの「加算」「減算」「乗算（積）」、および個別行列の「行列式（Determinant）」「逆行列（Inverse）」。
*   **ステップバイステップ解説**: 答えだけでなく、どの要素とどの要素を掛けて足したのか、すべての数式展開プロセスを出力。

### ④ 理解度判定小テスト (Practice & Quizzes)
学習の成果を確認するためのインタラクティブなクイズシステム。
*   **レベル別・カテゴリ別問題群**:
    *   *初級（概念と加減算）*: 行列のサイズ、基本演算。
    *   *中級（行列の積）*: 掛け算の成立条件、積の計算。
    *   *上級（線形変換と行列式）*: 変換行列の意味、逆行列や行列式の定義。
*   **多様な出題形式**: 選択肢（ラジオボタン）や、直接数値を入力するセル形式の回答入力。
*   **即時フィードバック**: 回答を送信すると、即時に「正解 / 不正解」を判定し、**詳細な途中式を含んだ計算プロセスの解説**を表示。
*   **スコアボードと達成度表示**: クイズ完了時に、正解率、かかった時間、詳細な結果分析を表示。

## 3. ユーザーインターフェース (UI) & インタラクション設計

*   **テーマとデザインシステム**:
    *   落ち着いたダーク・サイエンティフィック（Dark Scientific）テーマ（炭色 `zinc-900`/`slate-900` を背景に、数学的な精密さを演出するサイアン、バイオレット、エメラルドのアクセンカラー）。
    *   数式が読みやすい等幅フォント（JetBrains Mono）と、美しく視認性の高いInterを組み合わせ。
*   **アニメーション (`motion`)**:
    *   タブの切り替え時のスライド＆フェード効果。
    *   掛け算の計算ステップを「進む」「戻る」した際のハイライト移動や、計算数値のポップアニメーション。
    *   2Dグラフでのベクトル変形のイージング。
*   **レスポンシブ対応**:
    *   PCでの広大なダッシュボードビューを最適化しつつ、タブレットやスマートフォンでもグラフや行列入力が崩れず操作可能。

## 4. 開発・デプロイ方法

本アプリは、このサンドボックス環境で完全に動作するように構築されます。

### GitHubへのデプロイとPages公開について
本環境から直接自動でGitHubにPushすることはできませんが、ユーザー自身が以下の簡単なステップでGitHubリポジトリに反映し、GitHub Pagesで公開することができます。

1.  **ソースコードのダウンロード**:
    *   AI Studioの右上「Export to ZIP」またはメニューからプロジェクトをローカルにダウンロードします。
2.  **ローカルでのGit初期設定とPush**:
    ```bash
    git init
    git remote add origin https://github.com/ytaniytani/Basic-Introduction-to-Matrices.git
    git branch -M main
    git add .
    git commit -m "feat: インタラクティブ行列学習ラボの初期実装"
    git push -u origin main
    ```
3.  **GitHub Pagesでの公開**:
    *   ViteプロジェクトをGitHub Pagesにデプロイするためには、`gh-pages`パッケージなどを使用するか、GitHub Actionsで自動デプロイワークフローを設定します。
    *   最も簡単な方法（GitHub Actions）の構成用ファイルを `./.github/workflows/deploy.yml` に同梱します。リポジトリにPushするだけで自動的にビルドされ、GitHub Pagesにデプロイされます！
